\subsection{WBS dictionary}\label{sec:2.2}
This dictionary defines every Level 3 work package in the editable WBS. Effort is total person-hours. Duration is elapsed working days, excluding weekends. FS = finish-to-start. SS = start-to-start. FF = finish-to-finish. +n days = working-day lag. Overlap is permitted within a phase. Data migration begins only after configuration approval. Milestone approvals are recorded as completion events, not additional work packages.


% Source GP4 Skeleton block 79
The original 53 delivery packages total 1,544 person-hours. WBS 1.3.1 adds 212 recurring PM hours, producing 54 packages and a quantified planning subtotal of 1,756 hours. Package 1.3.1 maintains the schedule, weekly delivery reporting, monthly written sponsor updates, risk/\allowbreak{}change records and Part 5 recurring coordination. It starts with 1.1.1 and continues through 8.3.2 using an SS/\allowbreak{}FF span. The PM owns the output. Retained action and decision logs provide acceptance evidence. Its allowance is 4 hours per project week \(\times\) 53 weeks, counted once. The earlier 4,080-hour charter capacity reference is not part of this package estimate. Departmental onboarding delivery, learner release time and incremental specialist/\allowbreak{}incident effort remain outside this subtotal. Their availability and funding must be confirmed before affected work or wave activation. The subtotal is not a claim that all implementation effort is quantified or funded.
